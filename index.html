📐 重心坐标 · 台球碰撞法（通用解法）

把三个坛子的酒量记为 (a, b, c) 坐标（a = 5两坛、b = 11两坛、c = 14两坛）， 对应等边三角形内的重心坐标（点到三边成比例的距离）：
蓝色粗实线是三角形的外边框，细蓝线是坐标网格；
绿色边界是坛子容量限制围成的"台球桌"，三条边依次为 a = 5、b = 11、c = 0；
🎯 靶心是目标平分点 (0, 7, 7)。
从起点 (0, 0, 14) 出发让台球沿坐标线做弹性碰撞，撞到目标点就得到解——这正是所有可能的倒酒方案！
✍️ 可直接手写/画线（触屏或鼠标）
点击「▶ 演示台球碰撞」，球会在每个碰撞点显示当前坐标 (a, b, c)。
